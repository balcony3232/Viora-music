# Viora Music v0.2 development status

## Implemented in this branch
- Black/purple Spotify-inspired Home, Search and Library navigation.
- Search results as compact song rows; session-only favourites.
- Mini-player with buffering indicator and playback status.
- Expanded Now Playing with play/pause, seek UI, shuffle/repeat controls.
- Audius search and native Media3 playback retained.
- YouTube search opens official YouTube website externally.
- SoundCloud search opens SoundCloud externally.

## Pending / not yet functional
- SoundCloud **native playback**: requires approved SoundCloud API credentials, compliant stream access and integration testing. The current SoundCloud button is external search only.
- YouTube native playback is not included.
- Artwork, permanent library persistence, proper seek-position synchronisation, playback queue, Spotify CSV import, home-screen widget controls, Discord Rich Presence and account sync.
- GitHub Actions compilation and real-device behaviour require verification.

## Development principle
Do not extract YouTube Music audio or bypass service restrictions. SoundCloud tracks should be streamed only when their API permits it.
